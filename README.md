## Featured Projects

### TrustVault: Secure Document Sharing for Teams

Private document storage with real server-side sessions, share links that can be revoked instantly, and a tamper-evident audit trail. Built in five days for the Snovasys hackathon.

- Server-side sessions with bcrypt, CSRF protection and two-tier login rate limiting
- Document-level permissions (owner, editor, viewer) with immediate revocation
- SHA-256 hash-chained audit log with database triggers that block edits and deletes
- Multi-tenant company workspaces with invitations and role-based access control
- 300+ automated tests with Vitest and Supertest, plus a documented threat model
